# Configurações

Referência para configurações que o usuário ajusta no Pi.

## Modelos

`defaultProvider`: Provedor padrão na inicialização.
`defaultModel`: Modelo na inicialização.

## Interação

`externalEditor`: Editor aberto.
`doubleEscapeAction`: O que fazer com 2x Esc.

## Sessões

`sessionDir`: Onde salvar as sessões.

## Compactação

`compaction.enabled`: Booleano para compactar automaticamente.
